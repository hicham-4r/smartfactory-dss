# Security Policy

## Supported Versions

This repository is an **educational and academic project**. Only the latest version available on the `main` branch is considered maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not disclose it publicly through GitHub Issues**.

Instead, report the vulnerability privately to the repository owner with:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected component or file
* The potential security impact
* Any suggested fix, if available

Security reports will be reviewed as soon as reasonably possible.

## Security Scope

This project includes components such as authentication, role-based access control, APIs, ERP integration, AI/ML services, and other application features. Security measures implemented in this repository are primarily intended for **educational, academic, and demonstration purposes**.

The project should not be deployed in a real production environment without additional security review, configuration, testing, infrastructure hardening, secrets management, monitoring, and compliance checks.

## Responsible Disclosure

Please allow reasonable time for a reported vulnerability to be investigated and addressed before publishing or sharing details publicly.

## Disclaimer

This software is provided for **educational and academic purposes only**. The author makes no guarantee that the project is free from security vulnerabilities and is not responsible for damages resulting from unauthorized, improper, or production use of the software.
